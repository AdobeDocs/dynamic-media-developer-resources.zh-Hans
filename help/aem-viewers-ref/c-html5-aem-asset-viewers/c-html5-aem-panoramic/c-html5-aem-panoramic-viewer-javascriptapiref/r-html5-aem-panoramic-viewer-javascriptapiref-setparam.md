# setParam{#setparam}

全景查看器的JavaScript API参考。

` setParam( *`名称，值`*)`

将查看器参数设置为指定的值。 参数是特定于查看器的配置选项或软件开发工具包修饰符。 此参数在`init()`之前调用。

如果将查看器配置信息与`config` JSON对象一起传递给构造函数，则此方法是可选的。
