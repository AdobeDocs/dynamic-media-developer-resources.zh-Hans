# setParams{#setparams}

全景查看器的JavaScript API参考。

` setParams( *`参数`*)`

将一个或多个参数设置为给定值。 方法参数语法与URL查询字符串相同。 即，它表示用`&`分隔的名称=值对。 就像在查询字符串中一样，名称和值使用UTF8进行百分比编码。 调用`init()`之前，必须调用此参数。

如果将查看器配置信息与`config` JSON对象一起传递给构造函数，则此方法是可选的。
